# Archivum

閱讀與書寫的紀錄工具。書、文章、書寫三種紀錄，加上佳句、單字、關鍵字。

## 開發

```bash
npm run dev       # http://localhost:4173
npm run storybook # 元件目錄，要看的時候才開（http://localhost:6006）
npm run dev:all   # 兩個一起
```

環境變數照 `.env.local.example` 複製一份成 `.env.local`。

## 資料

Postgres（Supabase），透過 drizzle 存取。schema 在 `src/lib/db/schema/`。

一列不再是「一本書」，是**一次閱讀**：`books` 記書本身，`readings` 記這次讀的那個版本
（ISBN、平台、頁數、日期）。同一本書讀第二次就是第二筆 reading，佳句與心得聚得回同一本書。

分類（領域、次領域、屬性、平台、語言）**沒有一份要維護的清單**——填了新的值就自己長出一個節點，
選單列的是你實際用過的值，用得多的排前面。領域與次領域是同一棵樹的父子節點。

私人旗標掛在類型與關鍵字身上，不是一筆一筆標：想藏「政治」就標那個節點。
未解鎖時**伺服器不會把那些紀錄送到瀏覽器**，統計與月曆也一樣。

> 2026-09 之前資料放在 Google Sheet。那份試算表沒有刪，但從遷移那天起不再同步，
> 只是靜態備份。

## 自動補齊資料

新增書籍時輸入書名就查；已存在的書在編輯頁按「重新抓取」。
只填**空著的**欄位，你自己打的內容一律不覆蓋。

來源都是免費、免申請的，照「補得到頁數／字數」的順序問下去，補齊就停：

| 來源               | 補什麼             |
| ------------------ | ------------------ |
| 讀冊 TAAZE         | 中文書頁數         |
| Pubu               | 電子書字數         |
| 讀墨 Readmoo       | 電子書字數         |
| 日本國會圖書館 NDL | 日文書頁數         |
| Google Books       | 頁數（英文書為主） |
| Open Library       | 頁數               |

比對書名時會算相似度，**不夠像就寧可留白，也不寫入可能錯誤的資料**。
讀墨在機房 IP 會被擋成 403，線上抓不到，本機才有。

## 資料檢查

設定頁會列出常見的小問題（日期格式、完成日早於開始日、頁數不是數字、書名重複等）。
**只是提醒，不會擋住任何操作，也不會自動改你的資料。**
